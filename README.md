🛒 Blinkit Sales Analysis Dashboard
📌 Project Overview

This project presents an interactive Sales Performance Dashboard built to analyze Blinkit's retail sales data. The objective of this analysis is to extract meaningful business insights related to:

Total Sales Performance

Outlet Establishment Trends

Product Category Performance

Outlet Size & Location Analysis

Customer Ratings

Inventory Distribution

The dashboard provides a clear, executive-level summary of key business KPIs and supports data-driven decision-making.

🎯 Business Objectives

Analyze overall revenue performance.

Compare sales across outlet sizes and outlet types.

Understand product category contribution.

Evaluate customer ratings and item visibility.

Identify high-performing outlet tiers and segments.
